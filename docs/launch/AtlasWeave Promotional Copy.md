### Description

Build a small visual map in Obsidian—and keep a link back to the passage behind an idea.

Try AtlasWeave 0.10.0 → https://github.com/astreos108/atlas-weave/releases/tag/0.10.0
Manual install guide → https://github.com/astreos108/atlas-weave#install

This demo builds two connected thoughts, adds an inline block link, reopens the saved board, and follows the link to its source passage. Try naming one connection from your own notes, then explaining it in your own words.

Demo setup: macOS, Obsidian 1.15.1, AtlasWeave 0.10.0. This workflow was checked in a separate clean vault. Broader platform and file coverage is still being tested. Installation is from GitHub; this is not a claim of Obsidian Community directory approval.

AtlasWeave is an independent project, inspired by visual tools including Whimsical, Miro, and others. It is unaffiliated with those products.

## Obsidian community post

**Title:** AtlasWeave: a visual board with inline links back to source passages

I’ve been building AtlasWeave for visual learning in Obsidian. This short demo shows a small workflow: pull out two ideas, label their connection, link one thought to a source block, then reopen the board and follow that link back to the passage.

The public 0.10.0 build passed that sequence in a separate clean vault on macOS / Obsidian 1.15.1. That is the scope of this demo; I’m still gathering feedback on other notes and setups.

Release: https://github.com/astreos108/atlas-weave/releases/tag/0.10.0
